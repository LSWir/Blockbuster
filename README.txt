BLOCKBUSTER (Rust + Slint) — один лёгкий .exe без Python, браузера и Qt
=======================================================================
Это порт утилиты на Rust. Окно на Slint (тёмная тема), ядро — то же, что в Python-версии.
Каталог получается тот же: index.html + log.txt + скрытая папка .catalog_cache на выбранном диске.

СБОРКА (один раз, на Windows)
  1. Установите Rust: https://rustup.rs (тулчейн x86_64-pc-windows-msvc) и Visual Studio Build Tools
     (компонент «Разработка классических приложений на C++»).
  2. Запустите build.bat → появится папка Blockbuster_portable (Blockbuster.exe + logos).
     Либо вручную:  cargo build --release   → target\release\Blockbuster.exe
  3. Проверка ядра (необязательно): test.bat  (cargo test).

ЧТО ЛЕЖИТ РЯДОМ С Blockbuster.exe (всё необязательно)
  logos\            — ваши логотипы кодеков и IMDb/TMDB/RT (имена как раньше: imdb.png, dtshd_ma.png и т.д.)
  Popcorn.json      — своя анимация шапки (иначе используется встроенная)
  ffprobe.exe, ffmpeg.exe (можно в подпапках ffmpeg\ или bin\) — дорожки, субтитры, обложки из MKV
  catalog_config.json — ключи и настройки; создаётся из окна («Ключи и настройки → Сохранить»).
                        Формат совместим с Python-версией; старый файл можно просто скопировать.
  libraries.json    — список сканированных дисков (для кнопок «Открыть фильм» в HTML), создаётся сам.

ВСТАВКА КЛЮЧЕЙ
  Ctrl+V в поле работает при английской раскладке. При любой раскладке — кнопка «Вставить» справа от поля.

КНОПКИ В HTML («Открыть фильм», «Показать на диске»)
  Протокол catalogopen:// регистрируется автоматически при первом сканировании (HKCU, права админа не нужны).
  Вручную:  Blockbuster.exe --register [буква_диска]   /   Blockbuster.exe --unregister
  Если переместили exe в другую папку — просканируйте диск заново или выполните --register.

ОГРАНИЧЕНИЯ ЭТОЙ ВЕРСИИ
  Только окно (консольного режима нет). Режимы --open/--register/--unregister работают без окна.
  При закрытии окна во время сканирования программа сначала останавливается и сохраняет найденное в кэш.
